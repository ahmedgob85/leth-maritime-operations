# LETH Maritime Operations

Create a new enterprise web application named LETH Operations.

This is a professional maritime crew transportation and fleet management system for LETH Agencies.

Build a modern, responsive dashboard using React, TypeScript and Tailwind CSS.

Design requirements:

Professional maritime identity.

Dark navy blue sidebar.

Clean white dashboard.

Modern enterprise interface.

Arabic and English language support.

Full RTL and LTR support.

Responsive desktop and mobile layout.

Create the main navigation:

Dashboard

Movement Management

Trips

Drivers

Vehicles

GPS Tracking

Maintenance

Documents & Permits

Expenses

Reports

Users & Permissions

Settings

For now, build the application layout and dashboard structure only.

Do not create fake operational data.
Do not build database integrations yet.
Do not pretend unfinished modules are functional.

The application should look professional and be designed for real business operations.
